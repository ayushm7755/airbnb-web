# WanderStay (Airbnb-inspired Web Application)

A full-stack Airbnb-inspired web application that allows users to discover, create, manage, and review property listings. The application provides a secure authentication system, image uploads through Cloudinary, session management, and a clean MVC architecture for scalability and maintainability. Built with modern web technologies, this project demonstrates real-world full-stack development practices using Node.js, Express.js, MongoDB, and EJS.

## ✨ Features

- 🔐 User Authentication (Sign Up / Login / Logout)
- 🛡️ Authorization for protected routes
- 🏠 Create New Listings
- ✏️ Edit Existing Listings
- 🗑️ Delete Listings
- 📸 Upload Images using Cloudinary
- ⭐ Add Reviews & Ratings
- ❌ Delete Reviews
- 💬 Flash Messages for user feedback
- 🍪 Session-Based Authentication
- 📱 Responsive User Interface
- 🗂️ MVC (Model-View-Controller) Architecture
